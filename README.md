# 🚛 HQX Dispatch Dashboard

A modern, responsive dispatch and logistics dashboard designed to provide fleet operators with a clean and intuitive interface for managing shipments, drivers, vehicles, and operational analytics.

## ✨ Features

* 📊 Modern dashboard UI
* 🚚 Fleet overview
* 📦 Shipment management
* 👨‍✈️ Driver management
* 🚛 Vehicle monitoring
* 📈 Analytics & statistics
* 🌙 Dark theme interface
* 📱 Responsive design
* ⚡ Fast loading performance
* 🎨 Clean and professional UI

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Responsive Design
* Modern UI Components

## 🎯 Purpose

This project was created to practice modern frontend development while designing a professional logistics dashboard with a focus on clean user experience and scalable interface design.
